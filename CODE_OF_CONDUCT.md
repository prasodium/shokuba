# Code of Conduct

Shokuba is a project for people who like building things together. To keep it a good place to do that:

**Be kind and assume good faith.** People arrive with different backgrounds and experience levels. Disagree with ideas, not with people.

**Be constructive.** Criticism should be specific and helpful. "This will break when X" beats "this is bad."

**Be welcoming.** Answer beginner questions patiently. Everyone was new once.

**Respect people's time and privacy.** No harassment, no doxxing, no unsolicited private messages, no sharing other people's personal information.

**Keep it professional.** No discriminatory, sexualised or demeaning language or imagery, and no personal attacks or trolling.

## Enforcement

Maintainers may edit or remove comments, commits, issues and pull requests that break these rules, and may temporarily or permanently block anyone whose behaviour is harmful.

To report a problem, contact the maintainer through GitHub (open a private security advisory or message [@prasodium](https://github.com/prasodium)). Reports are handled discreetly.

This applies in all project spaces — issues, pull requests, discussions — and when someone represents the project in public.
